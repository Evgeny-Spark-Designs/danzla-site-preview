# DanZla — Site Preview

Static preview containing two pages from the DanZla site build:

- `index.html` — homepage
- `all-products/bags/index.html` — bags catalog page (product card links are disabled placeholders; only the visual grid is shown)

This is a trimmed export for review purposes only — not the full site.

## Viewing locally

Serve the folder with any static file server, e.g.:

```
python -m http.server 8000
```

Then open `http://localhost:8000/`.
